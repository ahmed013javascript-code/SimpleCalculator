# 🧮 Ahmed's Scientific Calculator | آلة أحمد العلمية

A clean, modern Android scientific calculator app built from scratch using **Kotlin** and **Jetpack Compose**.

تطبيق آلة حاسبة علمية حديث وسريع لنظام الأندرويد، تم تطويره بالكامل باستخدام لغة **Kotlin** وتقنية **Jetpack Compose**.

---

## ✨ Features | المميزات

* **Basic Operations (العمليات الأساسية):** Fast addition (`+`), subtraction (`-`), multiplication (`×`), and division (`÷`) with zero-division protection.
* **Scientific Functions (العمليات العلمية):** Supports powers ($x^y$), square roots ($\sqrt{x}$), percentages ($\%$), and trigonometric functions ($\sin$, $\cos$ in degrees).
* **Calculation History (سجل العمليات):** Automatically saves previous calculations in a scrollable list with a dedicated clear button.
* **Smart Number Formatting (تنسيق ذكي للأرقام):** Displays clean integers without unnecessary trailing zeros (e.g., `43` instead of `43.0`).
* **Modern Material 3 UI (واجهة عصرية):** Built with Jetpack Compose for smooth performance and responsive layout.

---

## 🛠️ Tech Stack | التقنيات المستخدمة

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material Design 3)
* **IDE:** Android Studio

## 📥 Download & Install | التحميل والتثبيت

1. Go to the **[Releases](../../releases)** section on the right side of this repository.
2. Download the latest `AhmedCalculator-v1.0.apk` file to your Android device.
3. Open the file and allow installation from unknown sources if prompted.

1. انتقل إلى قسم **[Releases](../../releases)** في يمين الصفحة.
2. حمّل ملف `AhmedCalculator-v1.0.apk` على هاتفك أو جهازك اللوحي بنظام أندرويد.
3. افتح الملف وثبّت التطبيق مباشرة.
